密评工具箱 v2.0.0（免安装版）
================================

一、运行方式
1. 将压缩包解压到任意目录（建议不含中文或空格的短路径，例如 D:\CryptoEval）。
2. 双击目录中的“密评工具箱.exe”即可运行，无需安装、无需管理员权限。
3. 首次启动可能稍慢（解压运行时组件），之后正常。

二、系统要求
- Windows 10 / Windows 11（64 位）
- 建议 4 GB 以上内存；100 万 bit 随机性检测建议 8 GB 以上

三、SmartScreen 提示
本程序未购买代码签名证书。若 Windows 提示“Windows 已保护你的电脑”，
请点击“更多信息” → “仍要运行”。这是未签名程序的常规提示，不是病毒。

四、配置与日志
- 配置（主题、强调色、字号）：%APPDATA%\CryptoEval\密评工具箱\settings.ini
- 日志：%LOCALAPPDATA%\CryptoEval\密评工具箱\logs\app.log
删除上述目录即可恢复默认设置。

五、功能一览
- 常用工具：分数计算、常见编码转换、密文长度分析、P7 签名数据解析
- 密码算法校验：分组密码（AES/SM4/DES/3DES，XTS/GCM 等）、ZUC、GCM、哈希、MAC、SM2、RSA、密钥生成
- 协议分析：PCAP 加密数据提取（TLS/TLCP、ESP、IKE 证书）
- 数字证书：证书链验证、吊销检查（离线 CRL）、ASN.1 解析、CRL 校验
- 随机数检测：GM/T 0005-2021，支持文件/文本输入、20k/1M/100M/自动/自定义参数
- 电子签章：PDF（CMS 与国密电子印章容器）、OFD 签章链校验与文件完整性校验

六、已知限制
- 在线 OCSP 未提供，吊销检查使用离线 CRL。
- ZUC-256 / ZUC-MAC、EMAC/LMAC 等模式未提供，界面会明确标注。
- 随机数 100M 模式不启用线性复杂度与 Maurer 通用统计（纯 Python 性能原因）；
  1M 全项检测可能耗时数分钟，可随时点击“取消”。
- 电子签章：无法识别的私有容器会如实显示“未知”，不会误报通过。
